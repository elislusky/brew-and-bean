# Brew & Bean — Coffee Shop Landing Page

A responsive coffee shop landing page built with HTML5 and CSS3.

## About the Project

Brew & Bean is a responsive coffee shop website created as a front-end development portfolio project.

The goal of the project was to practice semantic HTML, modern CSS layout techniques, responsive design, and creating a clean user interface for different screen sizes.

## Features

- Responsive layout for desktop, tablet, and mobile devices
- Semantic HTML5 structure
- Responsive navigation
- Hero section
- Coffee menu section
- Call-to-action sections
- Flexbox layout
- CSS Grid
- Mobile-friendly design
- Basic accessibility considerations

## Technologies

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Web Design
